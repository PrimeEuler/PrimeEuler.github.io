# The graviton's pair at play: Stokes pair of a polarized tensor wave on the k4 background

The two graviton polarizations form a pair in the record's sense: Jones spinor
psi = (h_R, h_L); intensity pair (u, v) = (|h_R|^2, |h_L|^2); X/T = (u - v)/(u + v) is the
circular-polarization fraction (Stokes V/I); the pair's Bloch sphere is the Poincare sphere;
the polarization tensor of a pure state is a square, e_ij = eps_i eps_j (spin-2 as a square,
as chi chi^T is the crossing). On the trace-free slice of the 2x2 symmetric matrices the
polarization matrix has det = -|h|^2, eigenvalues +/- |h| -- the complementary slice to the
crossings (trace 2T, det 0).

Dynamics on the record's background (fingerprint mode equation, v14.996):
Q'' + 3H Q' + (3k^2 + 4)/tau^2 Q = 0 with H = 1/tau is an Euler equation,
p = -1 +- i sqrt(3(k^2 + 1)): Q ~ tau^-1 cos(omega ln tau + phase), omega = sqrt(3(k^2+1))
-- the record's tau^-1 decay (v14.991), log-periodic.

Played with k = 2 (omega = sqrt(15)), Q_R = cos(omega ln tau), Q_L = 0.6 cos(omega ln tau - pi/3):
- the normalized pair sweeps the FULL semicircle: V/I attains both vertices exactly --
  pure-R instants at the Q_L nodes (ln tau = 0.675, 1.486, 2.298, 3.109, ...),
  pure-L instants at the Q_R nodes (0.405, 1.216, 2.027, 2.839, ...),
  diagonal crossings (V/I = 0) twice per half log-period;
- the unnormalized pair shrinks while it sweeps: physical intensity ~ tau^-4 (radiation
  redshift) against the background's tau^-2 -- the wave dilutes away; the eternal ride is
  in the normalized (shape) variables only.
