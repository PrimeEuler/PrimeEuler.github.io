# Representation tests: candidates to replace the AM triplet, against the v14.996 fingerprint

Fingerprint (the full physical content any replacement must reproduce):
{background rho = C/a^2, w = -1/3} + {5 propagating dof: 2 tensor + 2 vector + 1 scalar}
+ {all sound speeds 1} + {universal gap Q tau^2 = 3k^2 + 4 with friction 3H} + {ghost-free}.

## Results

PASS (same physics):
- Stueckelberg / massive-gravity phonons: identical fields in new notation. Not an exit.
- General isotropic elastic medium: correct dof and structure, but the fingerprint's speed
  conditions c_T^2 = 2 eta/3 = 1 and c_L^2 = -1/3 + 8 eta/9 = 1 (v14.927 formulas) solve
  UNIQUELY to eta = 3/2, where the tensor mass (8 eta/3) H^2 = 4 H^2 also lands on the
  record's value. The elastic family contains exactly one fingerprint-matching member:
  the AM point. Within this family the fingerprint acts as a SELECTOR, not a coincidence.

FAIL by dof count (background-only matches): exponential scalar (v14.959), perfect fluid
w = -1/3 with imposed c_s = 1 (vorticity decays; no propagating vector phonons), k-essence /
P(X), 3-form (dual to a scalar), pair spinor chi (v15.014: decouples; its working sector is
the scalar in dress). All share the background and miss the vector sector.

FAIL by extra dof: f(R) effective source (scalaron = second scalar); vector triad of
gauge-flation type (extra scalar/vector modes, known scalar-sector pathologies).

FAIL structurally: cosmic-string network (same w, but active incoherent anisotropic stress;
no coherent phonon eigen-spectrum to match).

FAIL by gap shift: sigma model with S^3 target (dof correct) -- target curvature masses the
phonons, m^2 ~ (C/a^2)(1/l^2); relative to the fingerprint gap 4/tau^2 the shift is
3/(4 kappa l^2) at kappa C = 1, a pure number only if l is Planck-fixed by hand.
l -> infinity recovers the flat triplet.

## Conclusion

No tested representation reproduces the fingerprint except the triplet itself (under its
aliases) and the unique elastic point that is the triplet. The amplitude modulus is
representation-invariant across all full equivalents. The geometry-first reframing
(v14.919 metric primary, triplet a completion) remains the only move that changes the
question -- from "why this C" to "why this completion" -- and within the elastic family
the fingerprint supplies a partial answer to the latter: it selects the AM point uniquely.
kappa C = 1 remains a matching; G_derived = false.
