# EM vs dyon grids in parabolic coordinates (companion to the weld, v14.904)

Figure `grids_parabolic.png` (script `make_figure.py`): the cone's
(X, Y) = (offset, GM) plane with the canonical row/column parabola
mesh, drawn for the two dictionaries the weld relates.

Left: EM, h = 1, q = 1/2. Members x, y integers; crossings at
offsets (1/2)Z; pair products (k/2)^2; smallest parabolas' vertices
at +/-1/2; r = log n; the unit raw pair (1,1) is grid (1,1), shell
n = 1, on the r = 0 line Y = 1.

Right: gravitational dyons, h = 1/2, q = 1/4. Members in (1/2)Z;
offsets (1/4)Z; pair products (k/4)^2; vertices at +/-1/4; r =
log(n/4); the unit raw pair is grid (2,2), shell n = 4, on the same
geometric r = 0 line Y = 1 (r = log(xy) is one function; the grid
shell index n = xy/h^2 is what changes). The shell's other nodes,
grid (1,4) and (4,1) at X = +/-3/4, are circled. EM nodes are the
even sublattice of the dyon nodes (v14.731 sec. 4).

Reading: mesh offset lattice is (h/2)Z [D]; node = state forces
h = 2q (the weld's premise); vertices = +/-q - the pair quantum IS
the vertex; counting starts at the shell carrying the first
complete pair: n = 1 (EM) vs n = 4 (dyons).
