# v14.819 task 4 — admissible corrections: constraints and impact

Even-sector constants: c_inf = -0.1842688751, K = 2.55271,
beta = W_0/2 = 0.5663798151, gamma = -0.35474. Odd-sector
constants (folded in 2026-10-25 from the completed odd block run):
c_inf = -0.18300198, K = 2.55224, beta = W_0/2 = 0.5658549391,
gamma = -0.38076. Target for a corrected pair: N*R'(N) -> 0 with
N*R'(N) inside the frozen finite budgets (a stronger requirement
than the coefficient limit alone; the finite F1/F2 comparison must
be re-run for any concrete candidate — not done here).

## 1. No compact (finite-support) correction can work [D]

Let the compact trial change by any finite-support delta x'.
By the v14.819 sec.1 identity applied to the difference,
N * delta C(N) = delta c_inf + O(1/N) uniformly (signed-moment
bound as in TASK3.md), while the seed drift contributes
-(W_0/2) ln ln(n/4) -> -infinity to N*S(N), hence
+(W_0/2) ln ln(n/4) -> +infinity to N*R(N) regardless of the
compact change. The unbounded term is entirely seed-side. ∎

## 2. No input-side rescaling of the seed can work either [D]

The drift coefficient and the diagonal limit are the same number:
beta = (1/2) * lim (m * yhat_m) = W_0/2, and N * d_N y_N -> W_0.
Any modification of the input sequence yhat_m with a changed
asymptotic leading coefficient w* = lim m*yhat_m changes both:
drift becomes w*/2 and the diagonal becomes w*. Killing the
drift forces w* = 0, which also kills the diagonal — the seed
then cancels none of the bare source at far rows and
N*R(N) -> 1 - c_inf - (channel constants) != 0 generically
(the constants do not conspire to 1 - c_inf; for the frozen pair
they give K - W_0 = 1.41995 against a needed 1 - c_inf = 1.18427
even before the drift). Within the single-input-sequence ansatz
the obstruction is structural: yhat_m is simultaneously the
diagonal (at n = m) and the U-channel fodder (for all n != m),
and its 1/m tail is what both jobs require and forbid.

## 3. The smallest admissible shape: an action-level counter-term

A correction must therefore live in the action, not the inputs:
S'(n) = S(n) + CT(n), where CT is a counter-term with

  N * CT(N) = -1.36844 + 0.56638 * ln ln(n/4) + 0.35474 / ln n
              + o(1/ln n)          (even)
  N * CT(N) = -1.36923 + 0.56585 * ln ln(n/4) + 0.38076 / ln n
              + o(1/ln n)          (odd)

so that N*S'(N) = 1 - c_inf + o(1). Necessary properties:
(a) Far support / DM silence: CT must vanish to |N*CT(N)| <~ 1e-5
    on all region-1 and direct-middle rows. The DM certificate
    (v14.583) passed at 4.81e-6 against a 2.225e-5 allowance; a
    counter-term with N*CT ~ 0.03 at DM rows would contribute
    ~2.7e-2 in DM l2 — three orders over the allowance. An
    input-side change does NOT have this property automatically
    (far inputs feed DM rows through the channel sums); an
    action-level term supported on outputs n >= F0 has it by
    construction. WITH such support, v14.583 is untouched and
    does not need recertification.
(b) Its own provenance: CT must be generated by a defined
    approximant/channel construction in Lane A's framework (a
    phantom input family with no diagonal footprint, e.g. an
    auxiliary-grid family evaluated only through the (zV - U)
    channel sums, is the natural shape). Supplying that
    construction is Lane A's geometry, as v14.812-S sec.5 already
    flagged; this note fixes the exact asymptotic it must hit.
(c) l2 admissibility: CT(N) ~ (W_0/2)(ln ln N)/N is in l2 on the
    far half-line, same class as the bare source — no capacity
    obstruction at the coefficient level. The finite-budget
    question (does the corrected pair pass F1/F2?) is separate
    and can only be answered by a fresh composition.
(d) SEPARATELY: the F2 assembly band defect (TASK2.md sec.4) is
    an assembly bug, not a property of any trial: any future
    far composition must include the [S, 2S) input band (or set
    the tail split at S for F2 as for F1). Fixing it changes no
    definitions and no certificates' meanings, only the composed
    values; the v14.812-S verdict stands (TASK2.md sec.4 (ii)).

## 4. The same verdict in Lane A's v14.882 frame

Lane A (v14.882) splits the seed action as D_log y + E_diag y
+ S_off + S_pole and defines B_seed = lim N [E_diag y + S_off
+ S_pole], with cancellation requiring B_seed =
1 + c*M_z - alpha*L*P - W_0 = +0.05151 even / +0.05129 odd.
In that frame this note's result reads: B_seed does not exist;
the partial quantity is B_seed(N) = -(W_0/2) ln ln(n/4) +
(K - W_0) + O(1/ln N) -> -infinity, worth -0.13209 / -0.13109
at the F2 block centers - 0.184 / 0.182 BELOW the required
value and falling. Exact rational W_0, the Phi remainder
envelope, the E_diag bound, and the three-band derivation are
in w0_exact.json and TASK2B_THREEBAND.md. The v14.882 Gate-2
warning (no termwise 1/n interchange against the non-l1 seed)
is exactly the mechanism: the drift is the below-band
smooth-mean accumulation sum_{m<N} 1/(m l_m), which the
three-band treatment keeps whole rather than expanding.
