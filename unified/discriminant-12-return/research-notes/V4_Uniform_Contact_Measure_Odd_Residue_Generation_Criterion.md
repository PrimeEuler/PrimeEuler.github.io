# V4 Uniform Contact Measure — Odd-Residue Generation Criterion

Date: 2026-09-11

Status labels: **[D]** exact derived, **[I]** interpretation, **[G]** guardrail.

## 1. Setup

Assume throughout
\[
\gcd(n,6)=1.
\]
Write
\[
n=\prod_p p^{e_p}.
\]
All prime residues lie in
\[
U(12)=\{1,5,7,11\}\cong V_4.
\]
Let
\[
H(n):=\langle p\bmod 12:\ p\mid n\rangle\le U(12)
\]
be the subgroup generated by all prime residue directions appearing in the factorization of \(n\). Residue \(1\) contributes no new direction.

Define the odd-exponent residue subgroup
\[
\boxed{
H_{\rm odd}(n)
:=
\left\langle
p\bmod 12:\ p^{e_p}\parallel n,\ e_p\text{ odd}
\right\rangle.
}
\]
Again residue \(1\) is harmless.

Let
\[
C_r(n)=\#\{d\mid n:d\equiv r\pmod{12}\},
\qquad r\in\{1,5,7,11\},
\]
and define the normalized contact measure
\[
P_r(n)=\frac{C_r(n)}{\tau(n)}.
\]
By earlier results, \(P_r>0\) exactly on \(H(n)\).

## 2. Character coefficients

For a real character \(\chi\) of \(U(12)\), define
\[
D_\chi(n)=\sum_{d\mid n}\chi(d),
\qquad
\rho_\chi(n)=\frac{D_\chi(n)}{\tau(n)}.
\]
Prime-power factorization gives
\[
D_\chi(n)
=
\prod_{p^{e_p}\parallel n}
\sum_{a=0}^{e_p}\chi(p)^a.
\]
Hence:

- if \(\chi(p)=+1\), the local factor is \(e_p+1\);
- if \(\chi(p)=-1\) and \(e_p\) is odd, the local factor is \(0\);
- if \(\chi(p)=-1\) and \(e_p\) is even, the local factor is \(1\).

Therefore
\[
\boxed{
D_\chi(n)=0
\iff
\chi\text{ is nontrivial on }H_{\rm odd}(n).
}
\]
Equivalently,
\[
\boxed{
D_\chi(n)\ne0
\iff
\chi\in H_{\rm odd}(n)^\perp.
}
\]

For every \(\chi\in H(n)^\perp\), one has \(\chi(p)=1\) for every prime divisor of \(n\), so
\[
\boxed{
D_\chi(n)=\tau(n),
\qquad
\rho_\chi(n)=1.
}
\]

## 3. Exact uniformity theorem

The contact measure is uniform on its support subgroup \(H(n)\) iff
\[
P_r(n)=
\begin{cases}
1/|H(n)|,&r\in H(n),\\
0,&r\notin H(n).
\end{cases}
\]
For a finite abelian group, the uniform probability measure on \(H\) has Fourier transform equal to \(1\) on \(H^\perp\) and \(0\) outside \(H^\perp\).

Our divisor-contact Fourier coefficients are exactly \(\rho_\chi\). Thus uniformity on \(H(n)\) is equivalent to
\[
\rho_\chi=1\quad(\chi\in H(n)^\perp),
\qquad
\rho_\chi=0\quad(\chi\notin H(n)^\perp).
\]
The first condition is automatic. The second holds iff every character nontrivial on \(H(n)\) is also nontrivial on \(H_{\rm odd}(n)\), i.e.
\[
H_{\rm odd}(n)^\perp=H(n)^\perp.
\]
Finite-group duality then gives
\[
\boxed{
H_{\rm odd}(n)=H(n).
}
\]
Therefore:

\[
\boxed{
\text{The divisor-contact measure is uniform on its support subgroup}
\iff
H_{\rm odd}(n)=H(n).
}
\]

This is the general exponent-parity extension of the squarefree orbit theorem.

## 4. Rank classification

### Rank 0
If \(H(n)=\{1\}\), then all prime divisors are \(1\pmod{12}\). The support consists only of residue \(1\), so uniformity is automatic.

### Rank 1
Suppose
\[
H(n)=\{1,g\},\qquad g\in\{5,7,11\}.
\]
Then
\[
\boxed{
\text{uniformity on }\{1,g\}
\iff
\text{at least one prime }p\equiv g\pmod{12}
\text{ occurs to odd exponent.}
}
\]
If every such exponent is even, then \(H_{\rm odd}=\{1\}\), and the contact weights are biased toward the identity residue.

### Rank 2
Suppose
\[
H(n)=V_4.
\]
Then uniformity on all four unit residues requires
\[
H_{\rm odd}(n)=V_4.
\]
Since any two distinct nontrivial elements of \(V_4\) generate the group,
\[
\boxed{
\text{full four-class uniformity}
\iff
\text{odd exponents occur in at least two distinct nontrivial residue directions.}
}
\]
Examples of sufficient odd-residue pairs are
\[
\{5,7\},\qquad \{5,11\},\qquad \{7,11\}.
\]
A single odd residue direction cannot annihilate all three nontrivial character channels.

## 5. Character-channel form

For \(H=V_4\), uniformity is equivalent to
\[
\boxed{
D_{-4}(n)=D_{-3}(n)=D_{12}(n)=0.
}
\]
Using the exact zero criteria:

- \(D_{-4}=0\) iff some odd-exponent prime lies in residue \(7\) or \(11\);
- \(D_{-3}=0\) iff some odd-exponent prime lies in residue \(5\) or \(11\);
- \(D_{12}=0\) iff some odd-exponent prime lies in residue \(5\) or \(7\).

These three simultaneous conditions are equivalent to the odd-residue directions generating \(V_4\).

## 6. Squarefree case recovered

If \(n\) is squarefree, every prime exponent is odd. Hence
\[
H_{\rm odd}(n)=H(n),
\]
so the contact distribution is automatically uniform on its support subgroup. This recovers the squarefree theorem directly.

Thus squarefreeness is not the essential condition. The essential condition is:
\[
\boxed{
\text{odd-exponent residue directions generate the same subgroup as all residue directions.}
}
\]

## 7. Bias as failure of odd-generation

When
\[
H_{\rm odd}(n)\subsetneq H(n),
\]
there exists at least one character \(\chi\) such that
\[
\chi|_{H_{\rm odd}}=1,
\qquad
\chi|_{H}\not\equiv1.
\]
For such a character,
\[
D_\chi(n)>0,
\]
so a nontrivial Fourier mode survives and the contact measure cannot be uniform on \(H\).

This identifies the source of bias exactly: it is the survival of characters that distinguish residue directions present only through even-exponent prime powers.

## 8. Guardrails

**[G]** The factor \(1/4\) appearing in the inverse V4/Hadamard transform is only the group-Fourier normalization \(1/|V_4|\). It is not identified with the Casimir quarter, null-diamond midpoint norm, or factor-cell mixed-difference quarter.

**[G]** Uniformity concerns the distribution of divisor contacts among unit residue classes modulo 12. It is not a primality criterion.

**[G]** The theorem assumes \(\gcd(n,6)=1\). If factors 2 or 3 are present, divisors outside \(U(12)\) occur and the four unit characters no longer by themselves encode the full divisor-contact distribution.

**[G]** Character vanishing here is exact finite-group cancellation in divisor sums; it is not spectral cancellation.

## 9. Exact status

The main result is the exact equivalence
\[
\boxed{
P\text{ uniform on }H(n)
\iff
H_{\rm odd}(n)=H(n).
}
\]
It follows from the prime-power character factorization plus finite V4 Fourier duality.
