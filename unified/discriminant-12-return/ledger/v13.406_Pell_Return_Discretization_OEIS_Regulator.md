\[

\begin{pmatrix}

\[
x_n^2-3y_n^2=1.

By Cayley-Hamilton,

\[
g_{12}^{n+2}=4g_{12}^{n+1}-g_{12}^n,

so every matrix entry obeys the same second-order recurrence.

## 4. Mod-12 residue period of the canonical return [D]

Direct exact modular powering gives

\[
\operatorname{ord}_{12}(g_{12})=12.
\]

In particular,

\[
\boxed{g_{12}^{6}\equiv7I\pmod{12}},
\qquad
\boxed{g_{12}^{12}\equiv I\pmod{12}}.
\]

The same statement is visible in the quadratic unit:

\[
(2+\sqrt3)^6=1351+780\sqrt3,
\]

and therefore

\[
\boxed{(2+\sqrt3)^6\equiv7\pmod{12}},
\qquad
\boxed{(2+\sqrt3)^{12}\equiv1\pmod{12}}.
\]

The CRT components have orders

\[
\operatorname{ord}_{3}(g_{12})=6,
\qquad
\operatorname{ord}_{4}(g_{12})=4,
\]

so

\[
\operatorname{ord}_{12}(g_{12})=\operatorname{lcm}(6,4)=12.
\]
