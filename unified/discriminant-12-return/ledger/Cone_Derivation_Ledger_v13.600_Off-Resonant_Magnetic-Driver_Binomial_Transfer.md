## 1. [D] Tilted SU(2) propagator

Define
\[
g=\gamma B_1,
\qquad
\Omega=\sqrt{\Delta^2+g^2}.
\]

Then
\[
\boxed{
H_r=-\Delta J_z-gJ_x
=-\Omega(aJ_x+dJ_z),
}
\]
where
\[
a=\frac{g}{\Omega},
\qquad
d=\frac{\Delta}{\Omega},
\qquad
a^2+d^2=1.
\]

Hence the exact rotating-frame propagator is
\[
\boxed{
U_j(t)=e^{-iH_rt}
=e^{,i\Omega t(aJ_x+dJ_z)}.
}
\]

For the ideal circular drive this is exact; no rotating-wave approximation is introduced at this stage.

## 2. [D] Fundamental transfer parameter

In the spin-1/2 representation,
\[
J_i=\frac{\sigma_i}{2}.
\]

Writing
\[
c=\cos\frac{\Omega t}{2},
\qquad
s=\sin\frac{\Omega t}{2},
\]
gives
\[
U_{1/2}
=
cI+i s(a\sigma_x+d\sigma_z)
=
\begin{pmatrix}
c+ids&ias\\
ias&c-ids
\end{pmatrix}
\]
up to the chosen ascending/descending \(J_z\)-basis ordering.

The spin-flip probability is therefore
\[
\boxed{
p(t)
=
a^2s^2
=
\frac{g^2}{\Delta^2+g^2}
\sin^2\left(
\frac{t}{2}\sqrt{\Delta^2+g^2}
\right).
}
\]

Equivalently,
\[
\boxed{
1-p=|c+ids|^2.
}
\]

If the effective-field tilt angle \(\beta\) is defined by
\[
\sin\beta=\frac{|g|}{\Omega},
\qquad
\cos\beta=\frac{\Delta}{\Omega}
\]
up to orientation signs, then
\[
\boxed{
p=\sin^2\beta\,\sin^2\frac{\Omega t}{2}.
}
\]

Thus the transfer parameter factors into an axis-tilt fraction and a rotation-phase factor.

## 3. [D] Exact j=1 probabilities

Starting from the lowest-weight state \(|1,-1\rangle\), the spin-1 representation is the symmetric square of the fundamental spinor. Therefore
\[
\boxed{
P_{-1\to-1}=(1-p)^2,
}
\]
\[
\boxed{
P_{-1\to0}=2p(1-p),
}
\]
\[
\boxed{
P_{-1\to+1}=p^2.
}
\]

Normalization is exact:
\[
(1-p)^2+2p(1-p)+p^2=1.
\]

The endpoint probability is
\[
\boxed{
P_{-1\to+1}(t)
=
\left[
\frac{g^2}{\Omega^2}
\sin^2\frac{\Omega t}{2}
\right]^2.
}
\]

## 4. [D] Exact j=3/2 probabilities

Starting from \(|3/2,-3/2\rangle\), the spin-3/2 representation is the symmetric cube of the fundamental spinor. Hence
\[
\boxed{
P_{-3/2\to-3/2}=(1-p)^3,
}
\]
\[
\boxed{
P_{-3/2\to-1/2}=3p(1-p)^2,
}
\]
\[
\boxed{
P_{-3/2\to+1/2}=3p^2(1-p),
}
\]
\[
\boxed{
P_{-3/2\to+3/2}=p^3.
}
\]

Normalization is exactly the binomial identity
\[
(1-p)^3+3p(1-p)^2+3p^2(1-p)+p^3=1.
\]

## 5. [D][G] General extremal-state law

The two explicit cases expose the general SU(2) law. For an initial lowest-weight state \(|j,-j\rangle\), write
\[
r=m+j,
\qquad
r=0,1,\ldots,2j.
\]

Then
\[
\boxed{
P_{-j\to -j+r}(t)
=
\binom{2j}{r}
p(t)^r[1-p(t)]^{2j-r}.
}
\]

Thus the full population distribution is
\[
\boxed{
r\sim\operatorname{Binomial}(2j,p(t)).
}
\]

This is not a statement that the weighted path consists of independent Bernoulli transitions. It is the probability law generated by one irreducible spin-j SU(2) rotation, equivalently the symmetric-power representation of one fundamental spinor rotation.

## 6. [Audit] Independent direct matrix-exponential checks

The binomial law was checked independently against direct numerical diagonalization/exponentiation of
\[
H_r=-\Delta J_z-gJ_x
\]
rather than against the symmetric-spinor derivation.

Two nonzero-detuning test points were used:
\[
(\Delta,g,t)=(0.7,1.3,0.83),
\]
and
\[
(\Delta,g,t)=(-1.1,0.8,1.17).
\]

For \(j=1\), the maximum absolute discrepancy between the direct matrix-exponential populations and
\[
((1-p)^2,2p(1-p),p^2)
\]
was
\[
5.55\times10^{-16}
\]
at both test points.

For \(j=3/2\), the maximum absolute discrepancies against
\[
((1-p)^3,3p(1-p)^2,3p^2(1-p),p^3)

\[
3.89\times10^{-16}
\]
and
\[
4.44\times10^{-16}.
\]

These are binary64 roundoff-level agreements. They are an independent numerical audit of the exact symbolic SU(2) derivation, not themselves the source of exactness.

## 7. [D][Audit] Resonance limit

At resonance,
\[
\Delta=0,
\qquad
\Omega=|g|=|\gamma|B_1,
\]
so
\[
\boxed{
p_{\rm res}(t)
=
\sin^2\frac{|\gamma|B_1t}{2}.
}
\]

For \(j=1\),
\[
\boxed{
(P_{-1},P_0,P_{+1})
=
\left(
\cos^4\frac{|\gamma|B_1t}{2},
\frac12\sin^2(|\gamma|B_1t),
\sin^4\frac{|\gamma|B_1t}{2}

\]
exactly recovering v13.595.

For \(j=3/2\), with

}
\]
again exactly recovering v13.595.

## 8. [D] Detuning ceiling on endpoint transfer

Because
\[
\sin^2\frac{\Omega t}{2}\le1,
\]
the largest accessible transfer parameter is
\[
\boxed{
p_{\max}
=
\frac{g^2}{\Delta^2+g^2}.
}
\]

For any nonzero detuning,
\[
p_{\max}<1.
\]

Therefore a constant detuned circular drive cannot produce complete extremal-to-extremal inversion.

For \(j=1\),
\[
\boxed{
P_{-1\to+1}^{\max}
=
\left(
\frac{g^2}{\Delta^2+g^2}
\right)^2.
}
\]

For \(j=3/2\),
\[
\boxed{
P_{-3/2\to+3/2}^{\max}
=
\left(
\frac{g^2}{\Delta^2+g^2}
\right)^3.
}
\]

Generally,
\[
\boxed{
P_{-j\to+j}^{\max}
=
\left(
\frac{g^2}{\Delta^2+g^2}
\right)^{2j}.
}
\]

Thus endpoint inversion becomes progressively more sensitive to detuning as \(j\) increases.

## 9. [G] Relation to the cone-weighted path

The intrinsic edge weights remain
\[
\boxed{
Y_q=\sqrt{(j-q)(j+q+1)}
=\sqrt{T^2-X_q^2}.
}
\]

They determine the off-diagonal realization
\[
(H_r)_{q,q+1}
=
-\frac{g}{2}Y_q.
\]

Detuning adds the diagonal linear potential
\[
(H_r)_{q,q}=-\Delta q.
\]

The effective-field geometry
\[
\boxed{
\Delta^2+g^2=\Omega^2

\]
controls the common transfer parameter \(p(t)\), while the centered cone geometry
\[
\boxed{
X_q^2+Y_q^2=T^2
}
\]
controls how the same SU(2) rotation is represented as a weighted path in the \(J_z\) basis.

These are coordinated but distinct geometric levels; no claim is made that detuning is a missing coordinate of the intrinsic cone.

The dynamical chain is
\[
\boxed{
(B_1,\Delta)
\to
(\hat n,\Omega)
\to
p(t)
\to
\text{one SU(2) rotation}
\to
\binom{2j}{r}p^r(1-p)^{2j-r}.
}
\]

## 10. Guardrails

1. The exact binomial law here assumes an initial extremal state \(|j,-j\rangle\) (or, by symmetry, the corresponding highest-weight version). Generic initial \(m\) states require the full Wigner-D matrix and are not generally binomial in this simple form.

2. The parameter \(p(t)\) is a representation-level transfer parameter inherited from the fundamental spinor. It does not imply statistically independent physical edge transitions.

3. The direct matrix-exponential checks are binary64 numerical audits. Exactness comes from the SU(2) symmetric-power derivation and binomial identity.

4. The ideal circular-drive rotating-frame Hamiltonian is exactly time independent. A linearly polarized drive is a separate problem and introduces counter-rotating terms / an RWA question.

5. The intrinsic cone circle and the effective-field circle must remain conceptually distinct.

## 11. Promoted conclusion

For the exact detuned circular magnetic driver
\[
H_r=-\Delta J_z-\gamma B_1J_x,
\]
define
\[
\boxed{
p(t)
=
\frac{\gamma^2B_1^2}{\Delta^2+\gamma^2B_1^2}
\sin^2\left[
\frac{t}{2}
\sqrt{\Delta^2+\gamma^2B_1^2}
\right].
}
\]

Then an initial lowest-weight state obeys the exact population law
\[
\boxed{
P_{-j\to-j+r}(t)
=
\binom{2j}{r}
p(t)^r[1-p(t)]^{2j-r},
\qquad
r=0,\ldots,2j.
}
\]

For \(j=1\) and \(j=3/2\), direct matrix exponentiation at two independent nonzero-detuning points agrees with these formulas to binary64 roundoff, and the \(\Delta\to0\) limit exactly reproduces the resonant propagator formulas of v13.595.
