## 2. Compute the de Branges numerator

For w,z in C, use
\[
\overline{m_a(w)}=m_a(\bar w)
\]
and the corresponding sharp/reality symmetry of W_pi.

The numerator is
\[
N_a(w,z)
=
E_a(z)\overline{E_a(w)}
-
E_a^\sharp(z)\overline{E_a^\sharp(w)}.
\]
Substitute the Weyl forms:
\[
N_a
=
W_\pi(z)\overline{W_\pi(w)}
\Big[
(1-icm_z)(1+ic\bar m_w)
-
(1+icm_z)(1-ic\bar m_w)
\Big].
\]
The bracket simplifies exactly to
\[
2ic(\bar m_w-m_z).
\]
Thus
\[
\boxed{
N_a(w,z)
=
2ic\,W_\pi(z)\overline{W_\pi(w)}
[\overline{m_a(w)}-m_a(z)].
}
\]

## 3. de Branges kernel

With Suzuki/de-Branges convention
\[
K_{E_a}(w,z)
=
\frac{E_a(z)\overline{E_a(w)}
-E_a^\sharp(z)\overline{E_a^\sharp(w)}}
{2\pi i(\bar w-z)},
\]
we obtain
\[
\boxed{
K_{E_a}(w,z)
=
\frac{c}{\pi}
W_\pi(z)\overline{W_\pi(w)}
\frac{m_a(z)-\overline{m_a(w)}}{z-\bar w}.
}
\]
(The simultaneous sign reversal in numerator and denominator converts the expression from Section 2.)

## 4. Boundary-triple gamma kernel

For an ordinary boundary triple,
\[
m_a(z)-\overline{m_a(w)}
=
(z-\bar w)
\langle\gamma_a(z),\gamma_a(w)\rangle.
\]
Hence
\[
\boxed{
K_{E_a}(w,z)
=
\frac{c}{\pi}
W_\pi(z)\overline{W_\pi(w)}
\langle\gamma_a(z),\gamma_a(w)\rangle.
}
\]

This is the exact desired bridge.

## 6. Gauge interpretation

The bare gamma-field RKHS has kernel
\[
K_m(w,z)=
\frac{m_a(z)-\overline{m_a(w)}}{z-\bar w}.
\]
The de Branges kernel is
\[
\boxed{
K_{E_a}(w,z)
=
q_a(z)\overline{q_a(w)}K_m(w,z),
\qquad
q_a(z)=\sqrt{c/\pi}\,W_\pi(z).
}
\]
Thus W_pi is exactly the analytic gauge converting the meromorphic Weyl model into the entire de Branges model.

This gives a precise functional-analytic meaning to the characteristic normalization that previously appeared as an arbitrary multiplicative factor.

## 7. Consequence for convergence

To prove convergence of finite de Branges spaces/kernels it is enough to control:
1. m_a(z) -> m_infty(z) locally off poles;
2. the analytic gauges q_a(z) modulo zero-free real-entire factors.

For the normalization-free ratio
\[

\]
only (1) is required.

For full E_a or raw W convergence, both (1) and (2) are required.

This cleanly separates spectral/extension convergence from entire-function gauge convergence.
