## 1. One-function sharp symmetry [D]

From v13.788,
\[
F_a(z)=\widehat{T_a^{-1}e^x}(z).
\]

The source vector \(T_a^{-1}e^x\) is real because \(T_a\) is a real self-adjoint operator and \(e^x\) is real. Therefore
\[
\boxed{
F_a^\sharp(z)
:=
\overline{F_a(\bar z)}
=
F_a(-z).
}
\tag{1}
\]

Hence the reflection quotient is
\[
\rho_a(z)=\frac{F_a^\sharp(z)}{F_a(z)}.
\]

## 2. Intrinsic Hermite–Biehler generator [D]

Define
\[
\boxed{
\mathcal E_a(z)
:=
(z+i)F_a(-z).
}
\tag{2}
\]

Then
\[
\boxed{
\mathcal E_a^\sharp(z)
=
(z-i)F_a(z).
}
\tag{3}
\]

Suzuki's full real self-adjoint characteristic family becomes
\[
\boxed{
W(a,\theta;z)
=
C_a\left[
\mathcal E_a^\sharp(z)

e^{i\theta}\mathcal E_a(z)

}
\tag{4}
\]

Thus the entire theta-family is generated by a single sharp pair.

This \(\mathcal E_a\) is the intrinsic Hermite–Biehler generator of Suzuki's real self-adjoint extension family. It is distinct from the later project object \(E_a^{\rm HB}=W_\pi-cW_0\) associated with the fixed complex target boundary parameter.

## 3. Exact Schur function [D]

For the ordinary scalar boundary triple,
\[
m_a(z)-\overline{m_a(w)}
=
(z-\bar w)\langle\gamma_a(z),\gamma_a(w)\rangle.
\]

Setting \(w=z\in\mathbb C_+\),
\[
\operatorname{Im}m_a(z)
=
\operatorname{Im}z\,\|\gamma_a(z)\|^2>0.
\]

Therefore \(m_a\) is Nevanlinna/Herglotz.

Define its Cayley transform
\[
\boxed{
s_a(z)
:=
\frac{m_a(z)-i}{m_a(z)+i}.
}
\tag{5}
\]

Then
\[
\boxed{
|s_a(z)|<1
\qquad(z\in\mathbb C_+).
}
\tag{6}
\]

Using the exact one-function relation of v13.788,
\[
\boxed{
s_a(z)
=
\frac{z-i}{z+i}
\frac{F_a(z)}{F_a(-z)}
=
\frac{\mathcal E_a^\sharp(z)}{\mathcal E_a(z)}.
}
\tag{7}
\]

Consequently
\[
\boxed{
|\mathcal E_a^\sharp(z)|<|\mathcal E_a(z)|
\qquad(z\in\mathbb C_+),
}
\tag{8}
\]
so \(\mathcal E_a\) is Hermite–Biehler in the standard upper-half-plane orientation.

This also explains Suzuki's real-zero theorem for the family (4).

## 4. Relation to the reflection quotient [D]

\[

\tag{9}

equivalently
\[
\boxed{
\rho_a(z)
=
\frac{z-i}{z+i}\,s_a(z)^{-1}.

\tag{10}
\]

Thus the possibly meromorphic reflection quotient becomes a uniformly bounded holomorphic function after the fixed Cayley/Blaschke normalization.

## 5. Normal-family compactness [D]

The family
\[
\{s_a\}_{a>0}
\]
is uniformly bounded by \(1\) on \(\mathbb C_+\).

Therefore, by Montel's theorem,
\[
\boxed{
\{s_a\}
\text{ is a normal family on }\mathbb C_+.
}
\tag{11}
\]

Every sequence \(a_n\to\infty\) has a subsequence for which
\[
s_{a_{n_k}}\to s_*
\]
locally uniformly on \(\mathbb C_+\), with \(s_*\) holomorphic and \(|s_*|\le1\).

Hence precompactness of the finite spectral-shape observables requires no new operator estimate.

## 6. Vitali uniqueness gate [D]

Let
\[
s_\infty(z)
:=
\frac{m_\infty(z)-i}{m_\infty(z)+i},
\]
with the stabilized infinite Weyl function of v13.754–755.

Suppose there exists a set
\[
S\subset\mathbb C_+
\]
with an accumulation point in \(\mathbb C_+\) such that
\[
\boxed{
s_a(z)\to s_\infty(z)
\qquad(z\in S).
}
\tag{12}
\]

Because \(\{s_a\}\) is locally uniformly bounded, Vitali's theorem yields
\[
\boxed{
s_a\to s_\infty
\quad\text{locally uniformly on }\mathbb C_+.
}
\tag{13}
\]

Where \(s_\infty\neq1\), the inverse Cayley transform
\[
\boxed{
m_a(z)
=
i\,\frac{1+s_a(z)}{1-s_a(z)}
}
\tag{14}
\]
then gives
\[
\boxed{
m_a\to m_\infty
}
\tag{15}
\]
locally uniformly.

Thus full finite-to-infinite Weyl convergence does **not** require a priori local-uniform operator convergence. It is enough to identify the pointwise limit of one bounded scalar Schur observable on any uniqueness set.

## 8. New minimal analytic target [C]

The remaining finite-to-infinite spectral problem may now be attacked by proving, for example, pointwise convergence on a one-dimensional interior set such as
\[
z=iy,\qquad y\in I\subset(0,\infty),
\]
provided \(I\) contains an accumulation point in \(\mathbb C_+\).

Concretely,
\[
\boxed{
s_a(iy)
=
\frac{y-1}{y+1}
\frac{F_a(iy)}{F_a(-iy)}.
}
\tag{17}
\]

Thus one may target scalar Laplace-transform ratios of the single source-level resolvent vector
\[
T_a^{-1}e^x
\]
along the imaginary axis.

Pointwise identification of (17) with \(s_\infty(iy)\) on any interval would force the full local-uniform Weyl limit by Vitali.

## Result

The finite Suzuki Weyl family admits the exact Schur/Hermite–Biehler representation
\[
\boxed{
s_a(z)
=
\frac{m_a(z)-i}{m_a(z)+i}
=
\frac{\mathcal E_a^\sharp(z)}{\mathcal E_a(z)},
\qquad
\mathcal E_a(z)=(z+i)F_a(-z).
}
\]

The family \(\{s_a\}\) is automatically normal on \(\mathbb C_+\). Therefore the hard convergence problem has been reduced from proving local-uniform convergence directly to identifying the pointwise limit of one bounded scalar observable on any interior uniqueness set.
