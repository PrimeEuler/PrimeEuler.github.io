## 1. Correction of an overstrong informal phrase

The discussion immediately following v13.236 described the support dynamics as a “true finite-state graph.” That wording is too strong globally.

What has actually been proved is:

1. for fixed primitive discriminant `D`, fixed extra-prime support set `S`, and fixed crossing prime `q`, the exponent/cofactor direction is finite, because the crossing signal depends only on `h mod q`;
2. a genuinely new support prime acts through one of finitely many local labels `(p mod q, chi_D(p))`;
3. the set of possible support sets `S` is nevertheless unbounded.

A finite transition alphabet does **not** by itself imply a finite global state space. New support primes can continue to accumulate, and the integer-valued signal amplitudes need not remain in a finite set.

Therefore the correct statement is

\[
\boxed{\text{finite state on each fixed-support stratum, but not yet a finite global automaton.}}
\]

This guardrail supersedes only the informal post-v13.236 phrasing; it does not alter the exact theorem in v13.236.

## 2. Fixed-support state space

Let

\[
\chi_D(n)=\left(\frac Dn\right)
\]

be a primitive nonprincipal quadratic character of conductor `d=|D|`. Fix an extra-prime support set `S`, and write

\[
R_S=\prod_{p\in S}p,
\qquad
L_S=dR_S.
\]

Every carrier in this support stratum has the form

\[
M=L_Sh,
\]

where every prime divisor of `h` already divides `L_S`.

For an odd prime `q` coprime to `L_S`, v13.235 proves that the full crossing signal depends only on

\[
\bar h=h\pmod q.
\]

However, not every element of `F_q^*` need be reachable by exponent changes using the existing support primes. Define the **support multiplier subgroup**

\[
\boxed{
H_S(q):=\langle p\bmod q: p\mid L_S\rangle\le \mathbf F_q^\times.
}
\]

If the current cofactor state is `h`, then changing only exponents of primes already in the support moves the cofactor through exactly the multiplicative orbit

\[
\boxed{hH_S(q).}
\]

Thus the exact exponent-reachability state space is generally a coset of `H_S(q)`, not automatically all of `F_q^*`.

## 3. Proof of the exponent-orbit theorem

Increasing the exponent of an existing support prime `p|L_S` by one multiplies `h` by `p`. Repeating such moves multiplies `h` by an arbitrary element of the monoid generated by the residues of the support primes.

Because every nonzero residue modulo prime `q` is invertible and has finite order, nonnegative powers of each support residue already generate its full cyclic subgroup. Hence the reachable multipliers form precisely

\[
H_S(q)=\langle p\bmod q:p\mid L_S\rangle.
\]

Therefore

\[
\boxed{
\operatorname{Reach}_{\rm exp}(S,h)=hH_S(q).
}
\]

This is exact.

## 4. Resonance subset of a support stratum

Define the centered Legendre target

\[
\ell_q(k)=\left(\frac{k-(q-1)/2}{q}\right).
\]

For fixed `(D,S,q)`, define the resonance-state subset

\[
\boxed{
\mathcal R_{D,S,q}
:=
\{h\in\mathbf F_q^\times:
 f_{L_Sh,q,D}=+\ell_q\text{ or }-\ell_q\}.
}
\]

By v13.235, this is well-defined: choosing a different positive integer representative of the same `h mod q` in the same support stratum gives the same crossing signal.

The centered-involution theorem of v13.234 means no shift parameter is needed here: if an exact Legendre resonance exists, its zero is forced to the center `(q-1)/2`.

## 5. Exact resonance-return criterion inside a support stratum

Suppose the system is at support `S` and cofactor state `h`. Exponent changes alone can return to a Legendre resonance if and only if the reachable coset intersects the resonance subset:

\[
\boxed{
\text{resonance reachable by existing-support exponent moves}
\iff
hH_S(q)\cap\mathcal R_{D,S,q}\ne\varnothing.
}
\]

Proof: the exponent-orbit theorem says the reachable cofactor states are exactly `hH_S(q)`, while `\mathcal R_{D,S,q}` is exactly the set of resonant cofactor states. Their intersection is therefore necessary and sufficient.

This is the correct finite-state reachability theorem on a fixed support stratum.

## 6. Adding a genuinely new support prime

Let `p` be a new prime with `p\nmid L_Sq`. The support changes to

\[
S'=S\cup\{p\},
\qquad
L_{S'}=pL_S.
\]

If the old carrier is

\[
M=L_Sh,
\]

then immediately after adjoining the new support prime once,

\[
pM=L_{S'}h.
\]

So the cofactor label itself remains

\[
\boxed{h'=h.}
\]

The crossing signal changes nontrivially by the v13.236 operator

\[
\boxed{
f_{pM}=T_{p\bmod q,\chi_D(p)}f_M,
}
\]

while the available exponent multiplier subgroup expands from

\[
H_S(q)
\]

to

\[
\boxed{
H_{S'}(q)=\langle H_S(q),p\bmod q\rangle.
}
\]

This separates two effects of a new support prime cleanly:

1. an immediate signal transition `T_{r,sigma}`;
2. an enlargement, possibly strict, of the subsequent exponent-reachability orbit.

## 7. Exact post-adjunction return criterion

After adjoining `p`, exponent moves inside the enlarged support stratum can reach precisely

\[
hH_{S'}(q).
\]

Therefore the exact criterion for eventual resonance return without adding any further new support prime is

\[
\boxed{
hH_{S'}(q)\cap\mathcal R_{D,S',q}\ne\varnothing.}
\]

This criterion is stronger and more precise than saying that a new-prime transition may later “return.” It identifies exactly what must be computed:

- the finite subgroup `H_{S'}(q)`;
- the finite resonance subset `\mathcal R_{D,S',q}`.

No search over arbitrarily large exponents is required.

## 8. Original Discriminant-12 resonance: 24 -> 120 -> 240

Take

\[
D=-8,
\qquad q=7.
\]

The primitive conductor is `d=8`. The original carrier

\[
M=24=8\cdot3
\]

has

\[
S=\{3\},
\qquad L_S=24,
\qquad h=1.
\]

Its crossing signal is the exact resonance

\[
f_{24}=(-1,1,1,0,-1,-1,1)
=-\ell_7.
\]

Now adjoin the genuinely new support prime `p=5`. Then

\[
S'=\{3,5\},
\qquad
L_{S'}=120,
\qquad
h'=1.
\]

v13.236 gives

\[
f_{120}=(-1,2,-1,0,1,-2,1),
\]

so the immediate new-support state is not resonant.

But the enlarged support contains the conductor prime `2`, whose residue modulo 7 is `2`. Increasing the exponent of `2` once sends

\[
h=1\longmapsto2.
\]

The corresponding carrier is

\[
M=120\cdot2=240.
\]

Direct exact computation, already present in the v13.234/v13.235 resonance data and independently reproduced by external audit v13.237, gives

\[
\boxed{
f_{240}=f_{24}=-\ell_7.}
\]

Hence

\[
\boxed{1\notin\mathcal R_{-8,\{3,5\},7},
\qquad
2\in\mathcal R_{-8,\{3,5\},7}.}
\]

The shortest return in this enlarged support stratum is therefore one exponent increment of the prime `2`:

\[
\boxed{24\xrightarrow{\,+5\text{ support}\,}120
\xrightarrow{\,+1\text{ exponent of }2\,}240.}
\]

This is an exact example of “support transition followed by exponent-state resonance recovery.”

## 9. The support subgroup is already maximal in the original q=7 example

For `M=24`, the support primes are `2` and `3`. Modulo 7,

\[
\operatorname{ord}_7(3)=6,
\]

so `3` alone generates `F_7^*`. Consequently

\[
\boxed{H_{\{3\}}(7)=\mathbf F_7^\times.}
\]

Thus even before adjoining `5`, the exponent multiplier subgroup is the full six-state multiplicative group. Adding `5` does not enlarge the subgroup:

\[
H_{\{3,5\}}(7)=\mathbf F_7^\times.
\]

What changes at `24 -> 120` is therefore not exponent reachability but the support-dependent resonance subset `\mathcal R_{D,S,q}` itself.

This is an important structural point: new support can change the signal family even when it adds no new multiplicative cofactor reachability.

## 11. Correct graph object

For fixed `(D,q)`, define a layered support graph whose vertices are pairs

\[
(S,h),
\qquad h\in\mathbf F_q^\times,
\]

with each vertex decorated by its exact signal `f_{L_Sh,q,D}`.

There are two conceptually distinct moves:

1. **within-layer exponent reachability:** multiplication of `h` by elements of `H_S(q)`;
2. **support-adjunction edge:**
   \[
   (S,h)\to(S\cup\{p\},h),
   \]
   with the immediate signal transformed by `T_{p mod q,chi_D(p)}`.

Each individual support layer is finite. The full layered graph is generally infinite because there are infinitely many possible finite support sets `S`.

Thus the correct structural picture is

\[
\boxed{
\text{infinite support graph with finite cofactor fibers and a finite local transition alphabet.}
}
\]

This replaces the premature phrase “finite global automaton.”

## 12. Finite local transition alphabet

Although the global support graph need not be finite, v13.236 still gives a strong finiteness result. Every new prime is locally labelled by

\[
(r,\sigma)
= (p\bmod q,\chi_D(p))
\in\mathbf F_q^\times\times\{\pm1\}.
\]

Hence there are at most

\[
\boxed{2(q-1)}
\]

local support-transition operator types `T_{r,sigma}`.

Quadratic reciprocity may restrict which of these labels are actually realized by primes for a given `(D,q)`, but no stronger global finiteness follows without quotienting support histories by an additional equivalence relation.

## 13. Research consequence

The next classification problem is now well posed.

For `q=5` and `q=7`:

1. compute `\mathcal R_{D,S,q}` for the support strata occurring in the known resonance families;
2. compute `H_S(q)` and its cosets;
3. classify which support-adjunction labels `(r,sigma)` change `\mathcal R` in a way that permits a return;
4. identify when two different support sets induce the same decorated finite fiber and may therefore be quotient-equivalent.

Only after such an equivalence is proved would it be justified to call the quotient a finite automaton.

A particularly promising object is the decorated fiber

\[
\boxed{
\Phi_{D,S,q}:\mathbf F_q^\times\to\mathbf Z^q,
\qquad
h\mapsto f_{L_Sh,q,D}.
}
\]

Two support strata `S,S'` could be declared equivalent only if their decorated fibers agree after an explicitly proved relabelling. Determining whether only finitely many such fiber types occur for `q=5,7` is now an exact, testable question.

## 14. Guardrails

- The fixed-support cofactor dynamics are finite; the global support-set dynamics are not yet proved finite.
- A finite alphabet of operators `T_{r,sigma}` does not imply a finite orbit or finite automaton.
- The resonance-return criterion is an intersection statement in `F_q^*`; it does not claim that every support transition returns.
- `24 -> 120 -> 240` is an exact worked return path, not evidence that every new support prime admits a one-step exponent repair.
- No principal-paper theorem is revised by this research checkpoint.
