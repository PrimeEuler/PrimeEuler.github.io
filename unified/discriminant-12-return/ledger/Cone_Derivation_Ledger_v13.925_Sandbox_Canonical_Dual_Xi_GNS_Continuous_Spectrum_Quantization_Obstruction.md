## 0. Gate

v13.923 and External Audit Round 138 left two precise questions:

1. Why is the Pontryagin-dual circle the preferred carrier for the signed arithmetic fixed lattice?
2. Can the zero resonances be promoted from transform zeros to point spectrum of a self-adjoint operator?

This entry closes the first and gives a sharp answer to the second.

The dual circle is canonical for harmonic analysis of the fixed lattice: it is the full unitary-character spectrum of \(\mathbb Z\), equivalently the Gelfand spectrum of \(C^*(\mathbb Z)\).

The cone-derived pure Xi kernel also gives canonical self-adjoint operator models. In those models, however, the zeta ordinates are **orthogonality times / generalized null modes**, not \(L^2\) eigenvalues.

That distinction is exact.

## 1. The Pontryagin-dual carrier is canonical [D]

The arithmetic factor-exchange fixed locus from v13.573/917/923 is the signed lattice

\[
\Gamma=\mathbb Z
\]

in the root-sheet coordinate \(Y=m\).

Every unitary character \(\chi:\mathbb Z\to U(1)\) is determined by \(\chi(1)\). Write

\[
\chi(1)=e^{2\pi i\theta},
\qquad
\theta\in\mathbb R/\mathbb Z.
\]

Then

\[
\boxed{
\chi_\theta(m)=e^{2\pi im\theta}.
}
\]

Conversely every \(\theta\in\mathbb T:=\mathbb R/\mathbb Z\) defines such a character.

Hence

\[
\boxed{
\widehat{\mathbb Z}\cong\mathbb T.
}
\]

This is not a post hoc choice of carrier; \(\mathbb T\) is the complete irreducible unitary-character space of the fixed lattice.

Equivalently,

\[
\boxed{
C^*(\mathbb Z)\cong C(\mathbb T).
}
\]

So \(\mathbb T\) is the Gelfand spectrum of the group \(C^*\)-algebra generated by the fixed-lattice translation.

## 2. Spectral theorem version of the same statement [D]

Any unitary representation \(\pi\) of \(\mathbb Z\) is determined by the single unitary

\[
U=\pi(1).
\]

By the spectral theorem,

\[
\boxed{
U=\int_{\mathbb T} z\,dE(z).
}
\]

Therefore every unitary representation of the fixed lattice decomposes over the same character space \(\mathbb T\).

For the regular representation on \(\ell^2(\mathbb Z)\), the Fourier transform

\[
\mathcal F:\ell^2(\mathbb Z)\to L^2(\mathbb T)
\]

sends the lattice shift to multiplication by

\[
e^{2\pi i\theta}.
\]

Thus the dual-circle carrier used in v13.923 is the canonical harmonic spectral representation of the signed fixed lattice.

### Guardrail [G]

This statement is about harmonic representations of the exact additive coordinate lattice \(\mathbb Z\). It does not turn the full AM–GM cone into an additive group.

## 3. The selected heat dynamics on the canonical carrier [D]

From v13.923, the cone quadratic is

\[
q(m)=m^2.
\]

Schoenberg exponentiation gives the Fourier multiplier

\[
e^{-tm^2}.
\]

On \(L^2(\mathbb T)\), the Fourier modes

\[
e_m(\theta)=e^{2\pi im\theta}
\]

satisfy

\[
P_te_m=e^{-tm^2}e_m,
\]

with generator

\[
\boxed{
A=\frac{1}{4\pi^2}\frac{d^2}{d\theta^2},
\qquad
Ae_m=-m^2e_m.
}
\]

So the canonical dual carrier has the discrete Laplacian spectrum

\[
\boxed{
\sigma(-A)=\{m^2:m\in\mathbb Z\}.
}
\]

This point spectrum is forced by the fixed-lattice quadratic and is **not** the zeta-zero ordinate spectrum.

No relabeling of \(m^2\) as \(\gamma_n\) is justified by the cone construction.

## 4. Pure Xi kernel and its normalized positive measure [D]

v13.722 proved the exact representation

\[
\boxed{
\Xi(w)
=
\int_{\mathbb R}\Phi(\tau)e^{w\tau}\,d\tau,
}
\]

where

\[
\Phi(\tau)>0
\]

for every real \(\tau\), \(\Phi\) is even, and \(\Phi\) decays super-exponentially.

In particular,

\[
\boxed{
\Xi(0)
=
\int_{\mathbb R}\Phi(\tau)\,d\tau
>0.
}
\]

Define the probability measure

\[
\boxed{
d\nu_0(\tau)
=
\frac{\Phi(\tau)}{\Xi(0)}\,d\tau.
}
\]

## 5. Canonical Xi GNS / return-amplitude model [D]

Let

\[
\mathcal H_\Xi
=
L^2(\mathbb R,d\nu_0).
\]

Define

\[
(Qf)(\tau)=\tau f(\tau)
\]

on the maximal domain

\[
D(Q)=
\left\{
f:
\int_{\mathbb R}\tau^2|f(\tau)|^2d\nu_0(\tau)<\infty
\right\}.
\]

Then

\[
\boxed{
Q=Q^*.
}
\]

Let

\[
\Omega_0(\tau)\equiv1.
\]

Since \(\nu_0\) is a probability measure,

\[
\|\Omega_0\|=1.
\]

The unitary group generated by \(Q\) is

\[
U_t=e^{itQ},
\qquad
(U_tf)(\tau)=e^{it\tau}f(\tau).
\]

Therefore

\[
\boxed{
\left\langle
\Omega_0,U_t\Omega_0
\right\rangle
=
\frac{\Xi(it)}{\Xi(0)}.
}
\]

Hence

\[
\boxed{
\Xi(i\gamma)=0
\iff
\Omega_0\perp U_\gamma\Omega_0.
}
\]

Every critical-line zero ordinate is exactly an **orthogonality time** of the cone-derived Xi unitary flow.

Because \(\Xi(it)/\Xi(0)\) is the Fourier transform of a probability measure, it is a continuous positive-definite function; the cyclic GNS representation associated with this coefficient is unique up to unitary equivalence.

Thus the return-amplitude model is canonical downstream of the pure positive Xi kernel.

## 6. One common self-adjoint operator handles the full complex zero plane [D]

The critical-line case is only the balanced member of a larger exact family.

For any real \(\alpha\), \(\Xi(\alpha)>0\), because

\[
\Xi(\alpha)
=
\int_{\mathbb R}
\Phi(\tau)e^{\alpha\tau}\,d\tau
\]

has a strictly positive integrand.

Inside the **same** Hilbert space \(\mathcal H_\Xi\), define

\[
\boxed{
\Omega_\alpha(\tau)
=
\left(
\frac{\Xi(0)}{\Xi(\alpha)}
\right)^{1/2}
e^{\alpha\tau/2}.
}
\]

Super-exponential decay of \(\Phi\) gives \(\Omega_\alpha\in\mathcal H_\Xi\) for every real \(\alpha\), and

\[
\|\Omega_\alpha\|=1.
\]

Then

\[
\begin{aligned}
\langle
\Omega_\alpha,
e^{i\gamma Q}
\Omega_\alpha
\rangle
&=
\frac{1}{\Xi(\alpha)}
\int_{\mathbb R}
\Phi(\tau)e^{\alpha\tau}e^{i\gamma\tau}\,d\tau\\
&=
\boxed{
\frac{\Xi(\alpha+i\gamma)}{\Xi(\alpha)}.
}
\end{aligned}
\]

Therefore

\[
\boxed{
\Xi(\alpha+i\gamma)=0
\iff
\Omega_\alpha
\perp
e^{i\gamma Q}\Omega_\alpha.
}
\]

So the same self-adjoint multiplication operator \(Q\) realizes every complex zero as an orthogonality event of a tilted cyclic vector.

The critical line is precisely the balanced vector

\[
\boxed{
\alpha=0,\qquad \Omega_0=1.
}
\]

### RH reformulation [G]

RH can be restated as:

\[
\boxed{
\text{every nontrivial Xi-zero orthogonality event occurs for the balanced vector }\Omega_0,
}
\]

with no such zero event for any \(\Omega_\alpha\), \(\alpha\ne0\).

This is only an exact reformulation. It does not prove RH.

## 7. Spectrum of the Xi multiplication operator [D]

Because

\[
\Phi(\tau)>0
\]

for every real \(\tau\), the measure \(\nu_0\) is equivalent to Lebesgue measure on every finite interval and has support

\[
\operatorname{supp}\nu_0=\mathbb R.
\]

Therefore

\[
\boxed{
\sigma(Q)=\mathbb R.
}
\]

For any \(\lambda\in\mathbb R\), an eigenvector satisfying

\[
Qf=\lambda f
\]

would have to be supported on the singleton \(\{\lambda\}\). But

\[
\nu_0(\{\lambda\})=0.
\]

Hence

\[
\boxed{
\sigma_p(Q)=\varnothing.
}
\]

All spectral measures

\[
|f(\tau)|^2d\nu_0(\tau)
\]

are absolutely continuous with respect to Lebesgue measure. Thus

\[
\boxed{
Q\text{ has purely absolutely continuous spectrum }\mathbb R.
}
\]

Consequently the ordinates \(\gamma\) occurring in §5 are parameters of the unitary evolution, not eigenvalues of \(Q\).

This is the same spectral-type obstruction, in a new canonical Xi/GNS realization, that v13.767 found for the norm-line generator.

## 8. A second canonical operator: convolution by the pure Xi kernel [D]

There is an even more direct operator realization of the transform zeros.

Since

\[
\Phi\in L^1(\mathbb R)
\]

and \(\Phi\) is real and even, define the bounded convolution operator on ordinary \(L^2(\mathbb R)\):

\[
\boxed{
(K_\Phi f)(x)
=
\int_{\mathbb R}
\Phi(x-y)f(y)\,dy.
}
\]

Young's inequality gives boundedness, and evenness/reality gives

\[
\boxed{
K_\Phi=K_\Phi^*.
}
\]

Use the unitary Fourier transform

\[
(\mathcal Ff)(t)
=
\frac1{\sqrt{2\pi}}
\int_{\mathbb R}e^{itx}f(x)\,dx.
\]

The convolution theorem gives

\[
\boxed{
\mathcal F K_\Phi\mathcal F^{-1}
=
M_{\Xi(it)},
}
\]

multiplication by the real scalar function

\[
t\mapsto\Xi(it).
\]

Thus the pure Xi transform is literally the spectral multiplier of a bounded self-adjoint convolution operator.

## 9. Zero ordinates are generalized null modes, not \(L^2\) zero modes [D]

Formally/distributionally, the plane wave

\[
x\mapsto e^{-i\gamma x}
\]

is a generalized Fourier eigenfunction of \(K_\Phi\), with generalized eigenvalue

\[
\Xi(i\gamma).
\]

Hence at a critical-line zero,

\[
\boxed{
\Xi(i\gamma)=0
\Longrightarrow
K_\Phi e^{-i\gamma x}=0
}
\]

in the generalized/distributional sense.

This is the closest canonical spectral-null statement produced by the present cone chain.

But plane waves are not in \(L^2(\mathbb R)\).

Moreover, because \(\Xi\) is entire and not identically zero, its real zero set

\[
\{t\in\mathbb R:\Xi(it)=0\}
\]

is discrete and therefore Lebesgue-null.

If

\[
K_\Phi f=0
\]

with \(f\in L^2\), Fourier diagonalization gives

\[
\Xi(it)\widehat f(t)=0
\]

almost everywhere. Since the multiplier is nonzero almost everywhere,

\[
\widehat f=0
\]

almost everywhere, so

\[
\boxed{
\ker K_\Phi=\{0\}.
}
\]

Therefore

\[
\boxed{
\text{the zero ordinates are generalized null frequencies, not point-spectrum zero modes.}
}
\]

## 10. Zero belongs to continuous, not point, spectrum of \(K_\Phi\) [D]

Riemann–Lebesgue gives

\[
\Xi(it)\to0
\qquad
(|t|\to\infty)
\]

because \(\Phi\in L^1(\mathbb R)\).

Hence \(0\) lies in the essential range closure of the Fourier multiplier, so

\[
\boxed{
0\in\sigma(K_\Phi).
}
\]

Section 9 gives

\[
0\notin\sigma_p(K_\Phi).
\]

Since \(K_\Phi\) is self-adjoint and injective,

\[
\overline{\operatorname{Ran}K_\Phi}
=
(\ker K_\Phi)^\perp
=
L^2(\mathbb R).
\]

But \(K_\Phi\) is not boundedly invertible because the multiplier approaches zero and vanishes at the Xi ordinates.

Therefore

\[
\boxed{
0\in\sigma_c(K_\Phi),
}
\]

the continuous spectrum.

This makes the quantization obstruction exact.

## 12. Why arbitrary functional calculus would be circular [G]

Starting from the fixed-lattice Laplacian, one could formally choose a function \(F\) with

\[
F(m^2)=\gamma_m
\]

and define

\[
F(-A).
\]

That would manufacture the desired eigenvalues.

But \(F\) would have been chosen using the zero ordinates as input.

Likewise one could define a diagonal operator directly by

\[
He_m=\gamma_m e_m.
\]

Both constructions are tautological.

Hence a genuine Hilbert–Pólya gate must derive a new operator, boundary condition, compact perturbation, scattering phase, or determinant **without using the ordinates in its definition**.

## 13. What has closed [D]

### Pontryagin-dual representation question

Closed for harmonic analysis:

\[
\boxed{
\widehat{\mathbb Z}=\mathbb T
}
\]

is the full unitary-character spectrum of the signed arithmetic fixed lattice, and every unitary lattice representation decomposes over it.

So the dual circle is canonical, not optional, for the fixed-lattice harmonic problem.

### Exact operator meaning of the zero ordinates

Closed:

\[
\boxed{
\Xi(i\gamma)=0
\iff
\Omega_0\perp e^{i\gamma Q}\Omega_0
}
\]

and, more generally,

\[
\boxed{
\Xi(\alpha+i\gamma)=0
\iff
\Omega_\alpha\perp e^{i\gamma Q}\Omega_\alpha.
}
\]

Also,

\[
\boxed{
\Xi(i\gamma)=0
}
\]

marks a generalized zero mode of the self-adjoint convolution operator \(K_\Phi\).

### Point-spectrum question

Not closed positively; instead a no-go is established for the canonical carriers:

- \(Q\) has no point spectrum;
- \(K_\Phi\) has trivial \(L^2\) kernel;
- the fixed-lattice Laplacian has the wrong point spectrum \(m^2\).

## 14. Next gate [O]

The quantization problem is now sharply localized.

A successful next construction must convert the already-derived **orthogonality/generalized-null data**

\[
\Xi(i\gamma)=0
\]

into discrete point spectrum without inserting \(\gamma\) by hand.

The natural non-circular possibilities are now only structures that genuinely change spectral type, for example:

1. a boundary-value/self-adjoint-extension problem whose secular equation is derived from the cone current;
2. a compact or relatively compact perturbation producing discrete eigenvalues from the continuous carrier;
3. a scattering or relative Fredholm determinant whose zeros arise from a geometrically derived boundary/return operator;
4. an exact intertwiner to the independently source-faithful Suzuki/de Branges operator lane, if that lane supplies the needed boundary data.

Any route that merely applies an arbitrary function to \(m^2\), \(Q\), or the known zeros is circular and is excluded.
