## 1. Exact untwisted identities

Let

D(n)=sum_{k<=n} d(k)=sum_{k=1}^n floor(n/k),

T_n=n(n+1)/2.

Then exactly

D(n)=n H_n - sum_{k=1}^n {n/k}.

Define the A161664 quantity

A_n := T_n-D(n)=sum_{k=1}^n (k-d(k)).

Therefore

A_n = T_n-nH_n+sum_{k=1}^n {n/k}.

## 3. Smooth hierarchy

The exact discrete object D(n) has the harmonic envelope nH_n. The classical logarithmic main scale is n log n, but n log n alone is not the full Dirichlet main term. Using

H_n = log n + gamma + 1/(2n) + O(n^-2),

we obtain

nH_n = n log n + gamma n + 1/2 + O(1/n).

Also

D(n)=n log n +(2 gamma-1)n + Delta(n).

Hence

F_n=nH_n-D(n)
=(1-gamma)n+1/2-Delta(n)+O(1/n),

and

A_n=T_n-D(n)
= n^2/2 +(3/2-2 gamma)n-Delta(n).

The last identity is exact if Delta(n) is defined by the displayed exact normalization of D(n); its significance is that A_n carries precisely the same divisor-problem fluctuation with opposite sign, sitting on a quadratic triangular background.
