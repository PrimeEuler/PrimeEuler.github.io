# Cone Derivation Ledger v13.382 — V4 Squarefree Divisor-Contact Orbit Classification

**Date:** 2026-09-09

## Scope
Exact arithmetic continuation of v13.378-v13.379. This checkpoint classifies the divisor-contact residue vector for squarefree \(n\) with \(\gcd(n,6)=1\) by the subgroup of \(U(12)\cong V_4\) generated by the nontrivial prime residue classes.

No Casimir/null-diamond/mixed-cell identification is used.

## Setup
Let
\[
n=\prod_{i=1}^{\omega(n)}p_i,
\qquad \gcd(n,6)=1,
\]
with \(n\) squarefree.

Define
\[
C_r(n)=\#\{d\mid n:d\equiv r\pmod{12}\},
\qquad r\in\{1,5,7,11\}.
\]
Write
\[
\mathbf C(n)=(C_1,C_5,C_7,C_{11})^T.
\]

Each prime factor contributes the group-algebra factor
\[
\delta_1+\delta_{p\bmod12},
\]
so
\[
\boxed{
\mathbf C(n)=\mathop{*}_{p\mid n}(\delta_1+\delta_{p\bmod12}).
}
\]

## Residue support subgroup
Let
\[
S(n)=\{r\in\{5,7,11\}:\exists p\mid n,\ p\equiv r\pmod{12}\},
\]
and
\[
H(n)=\langle S(n)\rangle\le V_4.
\]
Primes \(p\equiv1\pmod{12}\) contribute \(2\delta_1\), so they scale every contact count by 2 without changing the support subgroup.

## Uniformity theorem
For squarefree \(n\), the divisor residue distribution is uniform on \(H(n)\):
\[
\boxed{
C_r(n)=
\begin{cases}
2^{\omega(n)}/|H(n)|,&r\in H(n),\\
0,&r\notin H(n).
\end{cases}
}
\]
Equivalently,
\[
\boxed{
\mathbf C(n)=2^{\omega(n)-\operatorname{rank}H(n)}\mathbf1_{H(n)}.
}
\]
Here \(\operatorname{rank}H\in\{0,1,2\}\) over \(\mathbf F_2\).

## Complete classification
### Rank 0
If all prime divisors are \(1\pmod{12}\), then
\[
\boxed{
\mathbf C=(2^\omega,0,0,0).
}
\]

### Rank 1
If exactly one nontrivial residue class occurs among the prime divisors, then the contacts are uniform on its order-2 subgroup:
\[
5:\quad \boxed{\mathbf C=2^{\omega-1}(1,1,0,0)},
\]
\[
7:\quad \boxed{\mathbf C=2^{\omega-1}(1,0,1,0)},
\]
\[
11:\quad \boxed{\mathbf C=2^{\omega-1}(1,0,0,1)}.
\]

### Rank 2
Any two distinct nonidentity elements of \(V_4\) generate the whole group. Hence if at least two of \(5,7,11\) occur among the prime divisors,
\[
\boxed{
\mathbf C=2^{\omega-2}(1,1,1,1).
}
\]

The factor \(1/4\) implicit in the uniform full-rank distribution is only \(1/|V_4|\). It is unrelated to the Casimir/mixed-difference quarter discussed elsewhere.

## Character-dual statement
For
\[
D_\chi(n)=\sum_{d\mid n}\chi(d),
\]
squarefreeness gives
\[
D_\chi(n)=\prod_{p\mid n}(1+\chi(p)).
\]
Therefore
\[
\boxed{
D_\chi(n)\neq0
\iff
\chi|_{H(n)}\equiv1.
}
\]
The surviving character channels are exactly the annihilator subgroup
\[
H(n)^\perp\subset\widehat{V_4}.
\]
Thus
\[
\boxed{|H|\,|H^\perp|=4}
\]
and
\[
\boxed{
\operatorname{rank}H+\operatorname{rank}H^\perp=2.
}
\]

Consequently:
- rank-0 contact support -> all four character channels survive;
- rank-1 contact support -> exactly two channels survive;
- rank-2/full support -> only the trivial character channel survives.

Explicitly,
\[
\{1,5\}=\ker\chi_{-4},
\quad
\{1,7\}=\ker\chi_{-3},
\quad
\{1,11\}=\ker\chi_{12}.
\]

## Entropy corollary
Normalize the contact vector by \(\tau(n)=2^{\omega(n)}\). Since it is uniform on \(H\), its base-2 Shannon entropy is
\[
\boxed{
\mathcal H(n)=\log_2|H(n)|=\operatorname{rank}H(n)\in\{0,1,2\}.
}
\]
This is only a finite-group support statistic.

## Structural interpretation
The squarefree unit-residue contact pattern is controlled by the subgroup generated by the nontrivial prime residues, while the set of nonzero divisor-character channels is its Pontryagin/finite Fourier annihilator. Thus physical residue support and character support are exact dual subgroup data.

This is a genuine V4 structural theorem within the arithmetic carrier; it requires no cross-context quarter identification.

## Guardrails
