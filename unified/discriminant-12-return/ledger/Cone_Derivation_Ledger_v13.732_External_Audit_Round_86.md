This audit's Round 85 pass verified only the trivial calculus (`i\cdot d/dx[e^{-izx}]=ze^{-izx}`) without checking whether that calculus correctly represents what the source-defined `\bar D` does to this particular non-core function — a gap in that round's verification, now corrected by v13.724 and independently confirmed against the source here. Consistent with this audit's standing practice, this is disclosed rather than quietly folded into the summary.
